# Telegram File Gate Bot

Бот принимает файл от админа, сохраняет Telegram file_id и выдаёт файл по уникальной deep-link ссылке после проверки обязательных каналов.

## Переменные Bothost

Создай:

- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_ID` — твой Telegram ID
- `DB_PATH` — `/app/data/bot.db`

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

## Важно

Для проверки подписки бот должен быть администратором обязательных каналов.

Для закрытых каналов добавь бота администратором и используй пересылку сообщения из канала при добавлении канала в админке.

## Получение ADMIN_ID

Можно временно написать боту и посмотреть свой Telegram ID через любого надёжного ID-бота. Не публикуй BOT_TOKEN.
