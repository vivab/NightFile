# Telegram File-Gate Bot

Бот выдаёт файл по прямой ссылке только после проверки подписки на канал/группу.

## Как это работает
1. Пересылаешь боту файл и пишешь `/addfile Название` **в ответ на него** — бот сохраняет
   `file_id` в базе и присылает готовую ссылку вида
   `https://t.me/имя_бота?start=file_5`.
2. Отдаёшь эту ссылку людям.
3. Человек жмёт ссылку → Telegram открывает бота с `/start file_5` →
   бот проверяет подписку (если настроена) → отдаёт файл.

## Команды администратора
(твой ID должен быть в переменной `ADMIN_IDS`, узнать свой ID — команда `/myid`)

Основной способ управления — команда **`/admin`**, она открывает панель с кнопками:

- **➕ Добавить файл** — бот попросит прислать файл, потом название → выдаст прямую ссылку `https://t.me/бот?start=file_ID`
- **🗑 Удалить файл** — список файлов кнопками, тап → подтверждение → удаление
- **✏️ Переименовать файл** — самостоятельная утилита: пришли/перешли любой документ, бот скачает его и вернёт с новым именем, которое ты укажешь (не связано со списком выдачи, просто удобный инструмент)
- **📃 Список файлов** — все сохранённые файлы и их ссылки
- **📡 Управление ОП** — обязательная подписка: добавляй каналы, группы или ботов
  - Канал/группа — бот проверяет подписку через Telegram API (**бот должен быть там админом**, иначе проверка не сработает и юзер просто пройдёт дальше)
  - Бот — проверить членство нельзя технически, добавляется **на доверии**, просто ссылка-кнопка
  - При получении файла по ссылке пользователю показываются кнопки на все цели ОП + «✅ Я подписался»
- **📢 Ссылка «Наш канал»** — эта кнопка отдельно от ОП, показывается в стартовом сообщении и **под каждым выданным файлом** (для рекламы/апсейла)
- **✉️ Приветственный текст** — текст, который видит юзер по `/start` без параметров
- **📊 Статистика** — количество пользователей, файлов, целей ОП

Старые текстовые команды (`/addfile`, `/files`, `/delfile`, `/setchannel`, `/setwelcome`, `/stats`) больше не нужны — используй `/admin`.

## Деплой через GitHub + бот-хостинг

1. Создай пустой репозиторий на GitHub, залей туда все файлы этого проекта.
2. В настройках хостинга подключи репозиторий (обычно — «Deploy from GitHub»).
3. Укажи Dockerfile как способ сборки (или Start command: `python bot.py`,
   Build command: `pip install -r requirements.txt`).
4. **Обязательно подключи persistent volume/диск и примонтируй его в `/app/data`**
   — там лежит SQLite-база (`bot.db`). Без этого все файлы, настройки и статистика
   будут обнуляться при каждом редеплое или рестарте контейнера.
5. Добавь переменные окружения:
   - `BOT_TOKEN` — токен от @BotFather
   - `ADMIN_IDS` — твой Telegram ID (и через запятую другие админы), например `123456789`
   - `DB_PATH` — можно не указывать, по умолчанию `/app/data/bot.db`
6. Запусти. В логах должно появиться `INFO:aiogram...` без ошибок.
7. Напиши боту `/myid`, чтобы убедиться что твой ID совпадает с `ADMIN_IDS`.
8. Настрой канал: `/setchannel https://t.me/mychannel @mychannel`
   и добавь бота админом в канал/группу, если хочешь жёсткую проверку подписки.
9. Загрузи первый файл через `/addfile`, получи ссылку и раздавай её.

## Локальный запуск (для теста)

```bash
pip install -r requirements.txt
export BOT_TOKEN=твой_токен
export ADMIN_IDS=твой_id
python bot.py
```
